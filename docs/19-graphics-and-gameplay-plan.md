## Context

After the extraction-hub and space-weather work (PRs #39–#47, main at 6728e54) the player's verdict is: the graphics are neither good nor stable, and several systems feel janky. Decisions taken in planning (the player's picks in **bold**):

- **One art style: cel-shaded with ink outlines.** Both current render styles (Classic, and High detail with its FX ladder 0–3, N8AO, bloom, half-float buffers, self-check, render report) are replaced by one stable look with no post chain. Nintendo principle: clear silhouettes, one accent colour per family, every item readable at every zoom.
- **Fixed isometric camera:** 4 rotations × 2 tilts, snap-rotated, free zoom. Each building gets a designed "best side".
- **Walk mode is removed.**
- **Survey drones become a real fleet** with tangible, distinct rewards.
- Gameplay fixes the player named: roads to extraction sites, excavators that "teleport" through each other, box-drag grading done by rovers over time, unpause by clicking a speed, distinct hub models, muted pits, surveys and outposts made legible, pop-ups that blend together.
- **Verification stays light per piece** (tsc, docs:check, the piece's own spec) with one full diagnostic wave at the end. Pacing is not a target.

## How the work is organised

Each **stream** is one agent in its own git worktree (`$SP/wt/<name>`, branch `work/<name>`, own Vite port and Playwright cache, WIP commit ≤ every 20 min, resume note `$SP/notes/<name>.md`). `$SP` is the session scratchpad. Rules that make the parallelism safe:

1. **Strict waves, at most 5 agents at a time.** A wave starts when the previous checkpoint has merged. Wave 1 is two sub-waves (1A, 1B) so that no more than 5 run at once; the coordinator may start a stream early only if its "needs" column is already merged.
2. **Owned files** are the stream's to restructure. Any other file it touches is **shared**: additive edits only (new exports, cases, fields), never reshaped. Conflicts are resolved as unions.
3. **Contracts first (W0d).** Interfaces two streams share exist before either stream starts, as *functional* stubs (they forward, draw, return a placeholder), so every stream's spec passes alone.
4. **Internal milestones (M1…Mn).** Every stream lists them; each ends in a WIP commit with `tsc` and the stream's spec green. They are the safe pause points inside a wave: a stream interrupted by a usage limit resumes from its last milestone via its note.
5. **Working protocol: code through a few checkpoints, then one test round** (the player's rule, 2026-09-30). Streams and merges run only cheap checks: `npx tsc --noEmit` at milestones, the stream's own new spec once at the end, `npm run docs:check` once, and `--reporter=dot 2>&1 | tail -15` for every Playwright run (never `line` or `list`). A checkpoint's gate is `npm run build` plus one quick boot test. Broad regression testing is batched into **test rounds** every two or three checkpoints: **Test round 1 after CP1b** (a full-suite run, the stale-spec repair D1–D4, fixes for real regressions), then code on through Wave 2, then **Test round 2 after CP2** (a full-suite run and fixes). An extra targeted test is run at once only when a merge looks risky (main no longer boots, or an agent reports an unexplained regression). No pacing probes.
6. **Generated docs (03, 04, 05) are never hand-merged.** On conflict take either side and run `npm run docs`; the coordinator regenerates once per checkpoint.
7. **No stream edits spec base URLs.** The boot code ignores `nolock`, `lowfx`, `style`, `fx` (only `safe` stays, as the shader-fault fallback). Wave 3 tidies the leftovers. This avoids 30 guaranteed one-line conflicts.
8. **Screenshots are deliverables:** seed 42, the home preset, day and night, saved under `$SP/shots/<stream>/` and sent to the player at the checkpoint.
9. **Save migrations live in `Game.loadFrom`** (`game.ts:332-399`); `save.ts` is only I/O and the blob type.
10. **Pause protocol:** the coordinator keeps `$SP/RESUME.md` (agents, ids, ports, statuses, merge order); a safe pause is any checkpoint, or mid-wave with every stream at a committed milestone; check-in triggers resume stopped agents after a limit reset.
11. **Agent brief:** every launch uses the template at the end.

A child hides, moves and is removed with its source (`haulers` hides an empty unit mesh, `links` removes a layer), so no hook is needed at those sites. The twin (`InkMesh`) reads its source's `geometry`, `instanceMatrix` and `count` through live getters: a geometry swap for an upgrade (`meshFor`, `unitGeometry`, `roverGeometry(pk)`) needs no re-pointing at all, and nothing is mirrored per frame. Its `raycast` is a no-op.
- **`oDir` is made by an instance hook, not on demand.** Every view from `withInstanceState` gets its `oDir` attribute (vec4: mitre direction times length, and the part's size in metres) at creation, from a cache keyed by the recipe's position buffer. An attribute added to a geometry after its first draw is never bound (three's VAO cache), so the twin cannot add it lazily. The mitre replaces the plan's plain smoothed normal: each face meeting at a vertex moves by exactly one width (capped at two), so box corners do not open and thin edges do not shrink.
- **Width.** `w = px · depth · 2·tan(fov/2) / viewportH` (CSS px), pushed in *world* space along the instance's rotation alone, so the work kit's scaled pieces get the same width. It is set from the camera and renderer in `Material.onBeforeRender`: nothing in `game.ts` per frame. **Deviation: the plan's fixed "half width under 0.4 m²" is a fade.** A part's ink is `smoothstep(2, 10, part size on screen in px)` (`FADE_PX`, the size being the side of a square of the part's largest face), so rails, ladders and window frames become lines and a far building is not a black blot; big parts always get the full width.
- **Print cut** as planned: the fragment shader discards above `iState.w` (the source's own print cut), so a half-printed building shows its hollow interior in ink up to the cut and nothing above it.
- **Variants.** `ink()` from `celStyle.ts` is read every draw. A: 2 px flat; B: 1.5 px flat (default); C: 1.5 px, each vertex's own cel colour darkened 60% as the eye sees it (not one family accent per structure: the per-vertex colour already carries the accent on trim). `__game.setInkVariant('A'|'B'|'C'|null)` overrides the constant for screenshots and tests; S1a's `?cel=` override reaches the ink through `ink()` with no change here.
- **Fault and safe mode.** `INK_MARKER` (`MBB_INK`) marks the program. `recoverFromShaderFault` has `'cel' | 'ink' | 'other'`: `'ink'` hides the outlines for the session (`inkFaulted()`, an alert "RENDER — outlines disabled") and is outranked by `'cel'` and `'other'` (safe mode hides them anyway: `setInkEnabled(false)` in `enableSafeMode`, back on in `disableSafeMode`). The material's `visible` is the one switch, so hidden outlines cost no draw calls.
- **Render info.** `getRenderInfo().outlines` is the number of outline meshes drawing (0 in safe mode or after a fault); `getRenderInfo().ink` is `{ on, faulted, meshes, drawn, instances, variant, px, tinted, k, list }`, `list` one row per twin (`of`, `count`, `sourceCount`, `sameGeometry`, `sameMatrices`, `dirs`, `material`).
- **Cost** (seed-42 base at home): +5 to +10 draw calls (one per structure type present, plus rovers, drones, walkers, wings, dishes, kit, hub units, links) and about +13% triangles; a rich colony base is 73 calls and 305k triangles. Outlines are not frustum-culled (the source's own draw is), so off-screen structures still pay their vertices.

#### As shipped: S4a

Branch `work/s4a`. The sim reserves ground; units wait. Files: `src/core/traffic.ts` (rewritten, ~600 lines, the header is the model in prose), `core/haul.ts` (`drive(h, speed, t, limit)`), `core/hubs.ts` (`unitTick`, `goDig(face -1)`, `facePoint`, `rampsOf`, `planTraffic`), `core/transit.ts` (`transitArrive`), `core/economy.ts` (one call), `core/state.ts` (`HaulState.claim`, `held`), `core/hubView.ts` and `core/fleetView.ts` (a "HELD UP" line), `core/game.ts` and `debug.ts` (below), `tests/traffic.spec.ts` (new, 7 tests). `spots.ts` needed nothing.

- **What is reserved.** Road cells, one unit a cell, and the cell it just left (a body is longer than a cell), plus each cut pit's ramp as one key (one unit at a time). A dock's `bay` cells are soft (parking never blocks) and off-road ground inside a zone is not reserved (the visual lanes keep units apart there). A unit digging, tipping or parked holds no ramp: only a unit driving on it does.
- **Runs.** A unit holds the run ahead: its path's road cells up to the next *boundary* (a road cell beside a `pass`, `hold` or dock bay, or a ramp) or the end of its path. **A road with no bay in reach is held 48 m ahead** (`HORIZON_M`), so before S3's bays exist two units on one haul road do not serialise the whole road; head-on there resolves on the ground beside it. All of a run is granted or none of it, except that a unit behind another going the same way gets the cells behind it (a convoy). A unit standing in a bay holds nothing ahead until it can have its whole next run.
- **Priority and the tick.** Loaded digger (cargo, or `toDrop`/`unload`) before empty before rover, ties by id. `planTraffic` (economy step 0, before `transitArrive`) plans every digger's claim in that order; the hub units then move in id order (`go`, from `unitTick`), and a leg that begins mid-tick asks again on the spot. Nothing is reserved under `TRANSIT.instant` (debug `instantTravel` also sets `TRAFFIC.bypass`).
- **Waiting and stepping aside.** A unit refused a cell stops at the centre of the cell before (`h.held` counts seconds). A lower-priority unit standing on a cell a higher one needs, and not moving, pulls into a `pass`/`hold` cell or a free dock bay beside it at once, else after 3 s onto the free ground (or a free road cell off the other's way) beside the road: the way there and back is put in front of `h.path`, the `route` the visuals follow is untouched. Held 20 s: it lets go of the ground ahead and steps aside; held 60 s (12 s for a unit asked to give way that has no bay or ground to step onto: a gridlock in a tangle of roads): it drives through, counted in `forced`. All four counters are in `getRenderInfo().life.traffic.sim` (`heldS`, `maxHeldS`, `pullIns`, `stepAsides`, `forced`, `overlaps` (road cells held by two units at the end of a plan)).
- **Holding bays.** `goDig(face -1)` parks in a `hold` cell of the target's zone (or its pit's zone: `RoadCell.hold` is the zone id), else a `pass` cell within 6 cells of a gate, else the gate as before; another waiting unit's spot is skipped. S3's haul roads carry these cells now (the holding-bay test runs on the bay a hub lays itself); the head-on tests build a road of their own with `setRoadFlags`, and a haul road with none behaves as above.
- **Rovers** (`roverStep`, called by `transitArrive`): **a rover holds no ground**. It waits for a digger's claim on the stretch its next second covers (its clock stands still, `RoverTrip.held` counts the seconds in a row, the ETA stretches in real time) and drives through after 20 s. ## Decisions taken in planning (not to re-open)

- Cel-shaded with ink outlines; fixed isometric camera; walk mode removed; survey drones as a fleet (the player's picks).
- Outlines by inverted hull, not a screen-space pass: no render target, no post chain, MSAA kept.

## Risks and mitigations

1. **Deleting High detail breaks something Classic silently used** (`buildingShader` exports, `floodlights` via `rocks`' `floodPatch`, `sky.skyDirection`, `lighting.sunStep`). Mitigation: W0b1's M1 "move exports" commit keeps `tsc` green before any deletion; `world/cel.ts` is the single registry.
2. **Reservation determinism and stalls.** Single-phase grants invert priority; two units can wait on each other. Mitigation: the two-phase tick, a 20 s bounded wait falling back to a step-aside, a counter in `getRenderInfo().life.traffic`, and `traffic.spec`'s `rescues 0` gate; rovers are a stretch goal, not a dependency.
3. **Test churn.** CP0 gates `render/world/ui`, which W0b1 rewrites; camera field renames ripple through classic/touch/render specs. Mitigation: `getRenderInfo().camera` names are frozen at W0b2, `info()` keeps its old keys as aliases until D4, and no stream edits spec URLs.
4. **Outline cost or a compile fault.** A second pass over every instanced class, and one shader fault could hide everything. Mitigation: the `MBB_INK` marker and hide-outlines fallback; `look.spec`'s budgets (≤ 80 calls, ≤ 300k triangles); half-width for thin parts.
5. **Stub-to-implementation drift** (S6↔S2a/S7, S4↔S3, S5↔S1, S2↔S1). Mitigation: every W0d stub does something real (forwards, draws a line, returns the quadcopter or an empty outline), so each stream's spec passes alone before its checkpoint.

Space weather F4–F6 (shielding, benefits, look and audio) and extraction Phases 6–8 (research reshuffle, Builder, look and migration) stay in docs/18. **F5 matters most for surveys:** it adds four more exploration-gated breakthroughs, the richest "tangible reward" for exploring; S6's pipeline is built so they drop in.
